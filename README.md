# ЭЖКСР - электронный журнал кружковой и секционной работы
## Описание
Приложение для автоматизации учета посещаемости, успеваемости и достижений в кружках и секциях

## Технологии
- Python 3.9+
- CustomTkinter
- SQLite + SQLAlchemy
- pytest, flake8, black

## Установка
pip install -r ruqeirements

## запуск
python main.py
